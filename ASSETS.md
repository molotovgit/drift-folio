# Assets

Every 3D model in `public/models/` is made from scratch for this project by the Blender
Python scripts in `tools/blender/` (car: `tools/blender/car/`, props: `tools/blender/props/`).
There are no third-party models, textures or scans. Per-asset triangle counts, node names
and materials are listed in [tools/blender/ASSETS.md](tools/blender/ASSETS.md).

Fonts: Barlow and Barlow Condensed from Google Fonts (SIL Open Font License).

Audio: none yet (M8 will add CC0 or self-made sounds and list them here).
